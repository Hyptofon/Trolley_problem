# Інструкція розгортання: Vercel (Hobby) + Upstash Redis (Free)

Цей документ містить покрокову інструкцію для розгортання проєкту **«Проблема вагонетки»** на **Vercel Hobby** із безкоштовним хмарним сховищем **Upstash Redis Free**.

> [!NOTE]
> Відповідно до Технічного завдання (Версія 2.0), використання Google Sheets, Google Apps Script, Cloudflare Pages чи окремого стороннього сервера повністю скасовано. Увесь застосунок працює як єдиний Next.js проєкт на Vercel.

---

## 1. Підготовка локальних секретів

Перед розгортанням у хмарі згенеруйте криптографічні секрети локально:

### 1.1. Генерація пароля адміністратора (`ADMIN_PASSWORD_HASH`)
Виконайте команду у терміналі проєкту, передавши ваш обраний пароль для доступу до панелі `/admin`:

```bash
npm run generate-hash "ВашНадійнийПароль2026!"
```

Скрипт згенерує безпечний рядок salted scrypt, наприклад:
```text
16384:8:1$c9767c7a4cfd3799dd22293b4ab18996$0ca90ac88d2cf93ba1f2b2df197ea363a42de8ca6f371e882846aed8354aee79db0acd3ace7c4a97fb32eac0dd4c21977b3dfcebbba4d96f5c17d9100c36153a
```
Збережіть цей рядок — його потрібно буде додати у змінні середовища Vercel.

### 1.2. Генерація секрету для HMAC ідентифікаторів (`VOTE_ID_HMAC_SECRET`)
Згенеруйте випадковий 32-байтний ключ:
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

## 2. Створення та налаштування проєкту у Vercel

### 2.1. Імпорт репозиторію
1. Увійдіть у свій акаунт [vercel.com](https://vercel.com).
2. Натисніть **Add New...** → **Project**.
3. Оберіть ваш Git-репозиторій і натисніть **Import**.
4. Vercel автоматично розпізнає **Framework Preset: Next.js**.

### 2.2. Підключення Upstash Redis (Free)
1. У панелі проєкту Vercel перейдіть у вкладку **Storage** (або **Marketplace**).
2. Оберіть **Upstash for Redis**.
3. Натисніть **Create Database**:
   - Оберіть тарифний план: **Free** (256 MB, 500,000 команд/місяць, $0/місяць).
   - Оберіть найближчий регіон (наприклад, Frankfurt/eu-central-1).
4. Підключіть базу до вашого проєкту (Connect Project).  
   Vercel автоматично створить змінні:
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`

### 2.3. Встановлення змінних середовища (Environment Variables)
У Vercel перейдіть у **Settings** → **Environment Variables** і додайте:

| Змінна | Значення | Призначення |
| --- | --- | --- |
| `ADMIN_PASSWORD_HASH` | `16384:8:1$...` | Salted scrypt хеш пароля для `/admin` |
| `VOTE_ID_HMAC_SECRET` | `64-значний hex рядок` | Секрет HMAC для знеособлення ID відвідувачів |
| `REDIS_KEY_PREFIX` | `trolley:production:v1` | Ізоляція ключів у Redis |
| `DEMO_MODE` | `false` | Суворий production-режим без demo-заглушок |

### 2.4. Деплой
1. Натисніть **Deploy** (або запустіть **Redeploy** у вкладці Deployments).
2. За кілька секунд застосунок буде зібрано та опубліковано за адресою `https://<project-name>.vercel.app`.

## 3. Перевірка після розгортання (Smoke Test)

1. **Головна сторінка (`/`):**
   - Відкрийте сайт на комп'ютері або смартфоні.
   - Перевірте відображення SVG-сцени та двох рішень («Не втручатися» та «Перевести стрілку»).
   - Зробіть вибір: переконайтеся, що відтворюється символічна анімація наслідку і з'являється нейтральне повідомлення подяки.
   - Оновіть сторінку: ваш голос має залишитися зафіксованим без можливості повторного голосування.

2. **Адмінпанель (`/admin`):**
   - Перейдіть за адресою `/admin`.
   - Введіть неправильний пароль: перевірте появу повідомлення про помилку.
   - Введіть вірний пароль: відкриється захищений дашборд із реальними лічильниками та відсотками.
   - Увімкніть **«Презентаційний режим»**: перевірте повноекранний вигляд для показу аудиторії.
   - Натисніть **«Вийти»**: сесія в Redis інвалідується, а прямий доступ до `/api/admin/stats` поверне HTTP 401.

3. **Перевірка даних у сховищі:**
   - В [Upstash Console](https://console.upstash.com) відкрийте **Data Browser**.
   - Перевірте наявність хешу `trolley:production:v1:counts` із полями `stay`, `switch` та `updatedAt`.
   - Дані лічильників можна скопіювати або зберегти після завершення експерименту.
