# Покрокова інструкція розгортання (Deployment Guide)

У цьому посібнику наведено точні, вичерпні інструкції для підключення Google Таблиці, налаштування Google Apps Script та публікації сайту на Cloudflare Pages.

---

## 1. Налаштування приватної Google Таблиці

1. Відкрийте [Google Sheets](https://sheets.new) та створіть нову порожню таблицю.
2. Назвіть таблицю, наприклад: `Trolley Problem Votes (Private)`.
3. Зверніть увагу на URL у браузері:
   ```text
   https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms/edit
   ```
   Скопіюйте ідентифікатор між `/d/` та `/edit` — це ваш `SPREADSHEET_ID`.
4. **Важливо:** Таблиця залишається **повністю приватною**. Не надавайте публічного доступу («Доступ для всіх за посиланням»).

---

## 2. Налаштування Google Apps Script Web App

1. У створеній таблиці перейдіть у верхнє меню: **Розширення (Extensions)** → **Apps Script**.
2. Видаліть наявний шаблонний код у файлі `Code.gs`.
3. Скопіюйте та вставте вміст файлу `google-apps-script/Code.js` із цього репозиторію.
4. На лівій панелі натисніть на іконку шестерні **Налаштування проєкту (Project Settings)**.
5. Прокрутіть до розділу **Властивості скрипта (Script Properties)** і додайте дві властивості:
   - `SPREADSHEET_ID`: вставте збережений ідентифікатор вашої таблиці.
   - `SHARED_SECRET`: згенеруйте надійний випадковий рядок (наприклад, 32 або 64 символи: `openssl rand -hex 32`).
6. Натисніть **Зберегти властивості (Save script properties)**.
7. Поверніться до редактора коду (`< > Редактор`).
8. У верхньому спадному списку оберіть функцію `setup` та натисніть кнопку **Виконати (Run)**:
   - Google попросить надати стандартні дозволи на доступ до вашої таблиці (натисніть «Переглянути дозволи», оберіть свій акаунт, «Додатково» → «Перейти до проєкту»).
   - Функція створить аркуш `Votes` із темною шапкою: `Timestamp | Participant ID | Choice`.

### 2.1. Публікація Web App
1. У правому верхньому кутку натисніть синю кнопку **Розгорнути (Deploy)** → **Створити розгортання (New deployment)**.
2. Натисніть на значок шестерні ліворуч від «Select type» та оберіть **Веб-застосунок (Web app)**.
3. Заповніть параметри:
   - **Description:** `Trolley Problem Production Web App`
   - **Execute as (Виконувати від імені):** `Me (ваш_email@gmail.com)`
   - **Who has access (Хто має доступ):** `Anyone (Усі)`  
     *(Це необхідно для того, щоб сервер Cloudflare Pages Functions міг надсилати POST-запити. Захист забезпечується обов'язковою перевіркою `SHARED_SECRET` у кожному запиті).*
4. Натисніть **Розгорнути (Deploy)**.
5. Скопіюйте отриманий **URL веб-застосунку** (закінчується на `/exec`).  
   Формат: `https://script.google.com/macros/s/AKfycbx.../exec`.

> [!WARNING]
> Якщо ви згодом вносите зміни до `Code.js`, обов'язково створіть **нова версія розгортання** (Deploy → Manage deployments → Edit → Version: New version → Deploy).

---

## 3. Налаштування Cloudflare Pages

### 3.1. Підключення репозиторію
1. Увійдіть до панелі [Cloudflare Dashboard](https://dash.cloudflare.com/).
2. Перейдіть до розділу **Workers & Pages** → **Create application** → вкладка **Pages** → **Connect to Git**.
3. Оберіть ваш репозиторій із кодом проєкту.

### 3.2. Налаштування збірки
- **Project name:** `trolley-problem` (або довільна назва)
- **Production branch:** `main`
- **Framework preset:** `Vite` (або `None`)
- **Build command:** `npm run build`
- **Build output directory:** `dist`
- **Root directory:** `/`

### 3.3. Налаштування секретів (Environment Variables)
У налаштуваннях проєкту Pages (**Settings** → **Environment variables** → для **Production**) додайте 4 секрети:

| Змінна середовища | Опис | Приклад значення |
|---|---|---|
| `APPS_SCRIPT_URL` | URL розгорнутого веб-застосунку Apps Script | `https://script.google.com/macros/s/AKfycb.../exec` |
| `APPS_SCRIPT_SHARED_SECRET` | Той самий спільний секрет, що вказано у Script Properties | `a7d8e2...32chars` |
| `ADMIN_PASSWORD` | Надійний пароль для входу організатора в `/admin` | `YourStrongAdminPassword2026!` |
| `ADMIN_SESSION_SECRET` | Випадковий 32+ символьний ключ для підпису HMAC cookies | `b4f9c1...32chars` |

4. Натисніть **Save and Deploy**. Cloudflare Pages автоматично збере клієнтський SPA та розгорне безсерверні функції з каталогу `functions/`.

## 4. Фінальний Production Smoke Test

Після завершення деплою виконайте контрольні перевірки:

1. **Голосування відвідувача:**
   - Відкрийте головну сторінку розгорнутого сайту `https://<your-project>.pages.dev/`.
   - Оберіть варіант «Не втручатися» або «Перевести стрілку».
   - Переконайтеся, що анімація вагонетки спрацювала, а екран показав «Дякуємо за вашу участь».
2. **Перевірка запису в таблиці:**
   - Відкрийте вашу приватну Google Таблицю.
   - Перевірте появу нового рядка з точною датою, згенерованим UUID та обраним варіантом (`stay` або `switch`).
3. **Захист від дублювання:**
   - Оновіть сторінку в тому самому браузері.
   - Переконайтеся, що сайт одразу показує збережений вибір, не відкриваючи повторного голосування.
4. **Вхід організатора:**
   - Перейдіть на сторінку `https://<your-project>.pages.dev/admin`.
   - Введіть неправильний пароль — має з'явитися повідомлення про помилку.
   - Введіть правильний пароль `ADMIN_PASSWORD`.
   - Переконайтеся, що завантажився дашборд із точними підрахунками та графіком.
5. **Презентаційний режим:**
   - Натисніть кнопку «Презентація».
   - Перевірте повноекранне відображення для показу на проекторі/великому моніторі.
6. **Вихід:**
   - Натисніть «Вийти» — сесія має бути завершена, а повторний запит до `/api/admin/stats` повертати 401.

## 5. Діагностика та усунення несправностей (Troubleshooting)

- **Помилка `502 Bad Gateway` або `UPSTREAM_ERROR` при голосуванні:**
  - Перевірте, чи значення `APPS_SCRIPT_SHARED_SECRET` у Cloudflare повністю збігається зі `SHARED_SECRET` у Script Properties Google Apps Script.
  - Перевірте, чи виконано деплой Apps Script як `Web app` з доступом `Anyone`.
- **Помилка `504 Gateway Timeout`:**
  - Google Apps Script має короткочасну затримку під час холодного старту. Повторіть запит кнопкою «Спробувати ще раз».
- **Дані не з'являються в таблиці, але повертається 200:**
  - Переконайтеся, що ви запускали функцію `setup` з редактора Apps Script для ініціалізації шапки аркуша `Votes`.
- **Сесія в `/admin` скидається або не зберігається:**
  - Перевірте, чи сайт відкривається за захищеним протоколом `https://`. Cookies створюються з атрибутом `SameSite=Strict; Secure; HttpOnly`.
- **Квоти Google Apps Script:**
  - Безкоштовні акаунти Google мають ліміт у 20 000 викликів URL Fetch та записів на добу, чого більш ніж достатньо для навчальних аудиторій та презентацій.
